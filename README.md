# メモ・タスク管理アプリ

「雑に残せて、ちゃんと見つかる」をコンセプトに開発した、
メモとタスクを一元管理できるWebアプリです。

## アプリ概要

普段LINEのKeepメモを利用する中で感じていた、

- 手軽に残せるが、後から情報を整理しにくい
- 過去の内容に情報を追加しにくい
- 小さな用事をタスクとして期限管理できない
- 情報が増えると、過去の内容を探しにくい

という課題を解決するために開発しました。

高機能なメモ・タスク管理アプリを目指すのではなく、

「Keepメモやブックマークのように雑に残せる手軽さを保ちながら、
必要になったときには整理して見つけられる」

ことを重視しています。

## 主な機能

- メモとタスクを同じ場所から記録
- タスクへの期限設定
- 期限順でのタスク表示
- 保存内容への詳細情報の追加・編集
- ジャンルによる分類
- キーワード・期間・ジャンルを組み合わせた検索
- カレンダーによる期限確認
